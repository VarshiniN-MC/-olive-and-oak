# Olive & Oak – Food Court & Drinks

**A Multi-Restaurant Food Ordering and Table Reservation Application**

Olive & Oak is a web-based food court application developed using Python and Flask. It brings multiple restaurants and their menus together on a single platform, allowing customers to explore food options, place orders and reserve dining tables.

## Features

- **Restaurant Discovery:** Browse multiple restaurants and explore different cuisines.
- **Food Categories:** Explore vegetarian and non-vegetarian dishes, desserts and beverages.
- **Search and Filters:** Find restaurants and dishes using available filters.
- **User Login:** Demo OTP-based login and account management.
- **Shopping Cart:** Add, remove and manage food items, with one restaurant per order.
- **Multiple Services:** Dine-in, takeaway and home delivery.
- **Table Reservations:** Check table availability and reserve dining tables.
- **Payment Simulation:** Demonstrate different payment methods without processing real transactions.
- **Offers and Discounts:** Apply available promotional codes.
- **Order History:** View previous orders and reservations.
- **Customer Reviews:** Submit ratings and reviews for eligible restaurant orders.

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/VarshiniN-MC/olive-and-oak.git
   ```

2. Open the project directory:

   ```bash
   cd olive-and-oak
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open the application in your browser:

   ```text
   http://127.0.0.1:5000/
   ```
